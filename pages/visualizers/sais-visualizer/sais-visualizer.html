S-Type & L-Type Classification

In a single backward linear pass, every suffix is classified. A suffix is S-type if it is lexicographically smaller than the suffix starting at the next character, and L-type if it is larger. This determines whether it will sort toward the end (S) or the beginning (L) of its character bucket.

🌟

LMS (Leftmost S) Positions

An LMS position is any S-type character immediately preceded by an L-type character. The substrings between LMS positions form a tiny, reduced version of the original string. SA-IS magically proves that if we can sort just these LMS substrings, we can build the entire suffix array from them.

🧲

The Magic of Induced Sorting

Instead of comparing strings, SA-IS places the LMS suffixes into the array, and then uses a left-to-right pass to induce the positions of all L-type suffixes, followed by a right-to-left pass to induce all S-type suffixes. Because we scan in exactly the right order, everything perfectly slots into its sorted position in O(n) time.
