Introduction to Ruby

Ruby is a dynamic, open-source programming language created by Yukihiro "Matz" Matsumoto in 1995. It was designed with a single guiding principle: make developers happy. Its clean, expressive syntax reads almost like English.

Why Learn Ruby?

  • Joyful to read — natural, English-like syntax
  • Convention over configuration — Ruby on Rails made web dev famously fast
  • Everything is an object — a pure, consistent OO model
  • Huge ecosystem — thousands of gems via gem install

Your very first Ruby program is one line:

Ruby 
puts 'Hello, World!'
Output
Hello, World!

No semicolons needed. Ruby uses newlines to end statements and end to close blocks — not curly braces {}. Indentation is convention, not syntax.

The Ruby REPL: irb

Type irb in your terminal for an interactive Ruby shell. Try an expression and Ruby prints its result with =>.

irb 
irb(main):001:0> 2 + 3
=> 5
irb(main):002:0> "ruby".upcase
=> "RUBY"

Installation & Setup

Install Ruby on your machine and verify you have a modern version (3.1+). For real projects, use a version manager like rbenv or RVM.

macOS

Install via Homebrew (recommended):

Bash 
brew install ruby

Windows

Download the installer from rubyinstaller.org and check the "Add Ruby to PATH" option during installation.

Linux

Install via your package manager:

Bash 
sudo apt update && sudo apt install ruby-full

Verify your installation by running ruby --version in your terminal. You should see ruby 3.x.x (or newer).

Bash 
ruby --version
# Expected: ruby 3.2.x (or newer)

Run a file with ruby hello.rb, or start the interactive REPL with irb. Need an editor? Try the built-in Ruby Editor right here.

Practice: Verify Your Setup

Confirm Ruby is ready to go on your machine:

  1. Check the version with ruby --version
  2. Create hello.rb containing puts "Hello, Ruby!"
  3. Run it with ruby hello.rb
Bash

Syntax & Variables

Ruby is dynamically typed — you don't declare a type. Variables are assigned with = and come in a few flavors based on their first character.

Ruby 
name = "Alice"       # local variable
AGE = 25              # constant (capitalized)
PI = 3.14159

puts name
puts AGE
puts PI.class
Output
Alice
25
Float

String Interpolation — #{"{}"}

Embed expressions directly into strings. This is the idiomatic way to build dynamic strings in Ruby.

Ruby 
city = "New York"
population = 8_400_000

puts "Welcome to #{city}!"
puts "#{city} has about #{population} residents."
Output
Welcome to New York!
New York has about 8400000 residents.
Type Example Description
Integer42Whole numbers
Float3.14Decimal numbers
String"hello"Text
Symbol:nameImmutable, lightweight identifiers
true / false / niltrueBoolean & "nothing" values
Array[1, 2, 3]Ordered collection
Hash{ a: 1 }Key-value pairs

Symbols vs Strings: :name (symbol) is immutable and memory-efficient — ideal for hash keys and identifiers. "name" (string) is mutable text.

Use .class to check any value's type, and nil? to test for nothing.

04

Control Flow & Methods

Ruby branches with if / elsif / else and even an unless (the "if not"). Blocks close with end.

Ruby 
score = 85

if score >= 90
  grade = "A"
elsif score >= 80
  grade = "B"
elsif score >= 70
  grade = "C"
else
  grade = "F"
end

puts "Score: #{score} → Grade: #{grade}"
Output
Score: 85 → Grade: B

unless & Case

unless runs a block when a condition is false — perfect for guard clauses. Use case/when for many branches.

Ruby 
status = :pending

case status
when :active   then puts "Running"
when :paused   then puts "Paused"
when :pending  then puts "Waiting to start"
else puts "Unknown status"
end

puts "You are not logged in" unless false
Output
Waiting to start
You are not logged in

Methods

Define methods with def ... end. The last evaluated expression is returned automatically — no explicit return needed.

Ruby 
def greet(name, greeting = "Hello")
  "#{greeting}, #{name}!"
end

def add(a, b)
  a + b
end

puts greet("Alice")          # Hello, Alice!
puts greet("Sam", "Howdy")   # Howdy, Sam!
puts add(3, 4)               # 7

def even?(n)
  n.even?
end

puts even?(4)   # true
puts even?(7)   # false

Predicate methods end in ? and return a boolean. Bang methods end in ! and mutate the receiver in place (e.g. array.sort!).

Practice: Control Flow & Methods
  1. Write classify(n) returning :positive, :negative, or :zero
  2. Write factorial(n) using recursion
  3. Write shout(text) returning the text uppercased with a !
Ruby 
def classify(n)
  return :positive if n > 0
  return :negative if n < 0
  :zero
end

def factorial(n)
  return 1 if n <= 1
  n * factorial(n - 1)
end

def shout(text)
  "#{text.upcase}!"
end

puts classify(5)     # positive
puts classify(0)     # zero
puts factorial(5)    # 120
puts shout("hello")  # HELLO!

Arrays & Hashes

Arrays and hashes are Ruby's workhorse collections. Arrays are ordered lists; hashes store key-value pairs. Both pair beautifully with the each iterator.

Arrays — Ordered & Mutable

Create arrays with [] or the Array.new shorthand.

Ruby 
fruits = ["apple", "banana", "cherry"]

puts fruits[0]        # apple
puts fruits[-1]       # cherry

fruits << "date"      # shovel operator (push)
fruits.unshift("kiwi")
fruits.delete("banana")

p fruits              # inspect
puts "Length: #{fruits.length}"
Output
apple
cherry
["kiwi", "apple", "cherry", "date"]
Length: 4

Ranges & Slicing

Ranges 1..5 (inclusive) and 1...5 (exclusive) turn into arrays with to_a.

Ruby 
nums = (1..10).to_a

p nums[2..4]        # [3, 4, 5]
p nums.first(3)     # [1, 2, 3]
p nums.last(2)      # [9, 10]
p nums.reverse      # [10, 9, ..., 1]

Hashes — Key-Value Pairs

Modern Ruby prefers the key: value syntax (symbol keys). Access with [] or the safe fetch.

Ruby 
person = {
  name: "Alice",
  age: 25,
  city: "New York"
}

puts person[:name]                 # Alice
puts person.fetch(:age, 0)         # 25
puts person.fetch(:email, "n/a")   # n/a

person[:email] = "alice@mail.com"
person[:age] = 26

person.each do |key, value|
  puts "#{key}: #{value}"
end
Output
Alice
25
n/a
name: Alice
age: 26
city: New York
email: alice@mail.com

Prefer fetch(key, default) over [] when a missing key should fall back gracefully — it avoids silent nil surprises.

Blocks, Procs & Lambdas

Blocks are Ruby's bread and butter — anonymous chunks of code passed to methods. each, map, and select all take blocks. Blocks become procs and lambdas when you need to store or pass them around.

Blocks — { } and do...end

Use { } for single-line blocks, do...end for multi-line. yield runs a passed block.

Ruby 
numbers = [1, 2, 3, 4, 5]

numbers.each { |n| puts "Count: #{n}" }

doubled = numbers.map { |n| n * 2 }
p doubled            # [2, 4, 6, 8, 10]

evens = numbers.select { |n| n.even? }
p evens              # [2, 4]

def repeat(times)
  times.times { yield }
end

repeat(3) { puts "Ruby!" }
Output
Count: 1
Count: 2
Count: 3
Count: 4
Count: 5
[2, 4, 6, 8, 10]
[2, 4]
Ruby!
Ruby!
Ruby!

Procs & Lambdas

A proc is a saved block created with Proc.new. A lambda is stricter: it checks arity and its return exits only itself, not the enclosing method.

Ruby 
square = Proc.new { |x| x * x }
cube = ->(x) { x * x * x }        # lambda shorthand

puts square.call(4)   # 16
puts cube.call(3)     # 27

def apply(list, proc)
  list.map { |item| proc.call(item) }
end

p apply([1, 2, 3], square)   # [1, 4, 9]
p apply([1, 2, 3], cube)     # [1, 8, 27]

double = proc { |x| x * 2 }  # same as Proc.new
Behavior Proc Lambda
return insideExits the enclosing methodExits only the lambda
Argument countLenient (fills with nil)Strict (raises ArgumentError)
Creationproc { } / Proc.newlambda { } / ->(x) { }

Object-Oriented Ruby: Classes & Modules

In Ruby, everything is an object. Classes define behavior, and modules bundle reusable behavior for mixing in or namespacing.

Classes & Instance Variables

@name is an instance variable. attr_accessor generates getters and setters automatically.

Ruby 
class Person
  attr_accessor :name, :age

  def initialize(name, age)
    @name = name
    @age = age
  end

  def introduce
    "Hi, I'm #{@name} and I'm #{@age} years old."
  end

  def to_s
    "#{@name} (#{@age})"
  end
end

alice = Person.new("Alice", 25)
puts alice.introduce
alice.age=(26)
puts alice.to_s
Output
Hi, I'm Alice and I'm 25 years old.
Alice (26)

Inheritance — super

Use < to inherit. super forwards to the parent class.

Ruby 
class Animal
  attr_reader :name

  def initialize(name)
    @name = name
  end

  def speak
    "..."
  end
end

class Dog < Animal
  def speak
    "#{@name} says woof!"
  end
end

class Cat < Animal
  def speak
    "#{@name} says meow!"
  end
end

puts Dog.new("Rex").speak
puts Cat.new("Milo").speak
Output
Rex says woof!
Milo says meow!

Modules — Mixins & Namespacing

include mixes module methods into a class (as instance methods); extend adds them as class methods. Comparable and Enumerable are famous built-in mixins.

Ruby 
module MathHelpers
  def squared
    self * self
  end
end

class Integer
  include MathHelpers
end

puts 7.squared       # 49

module Greeting
  def hello
    "Hello from Greeting!"
  end
end

class Greeter
  include Greeting
end

puts Greeter.new.hello
Practice: Classes & Modules
  1. Define a BankAccount with balance, deposit, and withdraw
  2. Prevent withdrawing more than the balance (return false)
  3. Add a SavingsAccount < BankAccount that adds interest
Ruby 
class BankAccount
  attr_reader :balance

  def initialize(balance = 0)
    @balance = balance
  end

  def deposit(amount)
    @balance += amount
  end

  def withdraw(amount)
    return false if amount > @balance
    @balance -= amount
    true
  end
end

class SavingsAccount < BankAccount
  def interest
    @balance += @balance * 0.05
  end
end

account = SavingsAccount.new(100)
account.deposit(50)
puts account.withdraw(200)   # false
puts account.withdraw(20)    # true
account.interest
puts account.balance         # 136.5

Error Handling

Ruby uses begin / rescue / ensure to handle exceptions gracefully instead of crashing. Every error is an object — StandardError and its subclasses.

Ruby 
def safe_divide(a, b)
  begin
    a / b
  rescue ZeroDivisionError => e
    "Cannot divide by zero: #{e.message}"
  rescue NoMethodError
    "Invalid operands"
  ensure
    puts "Division attempt finished"
  end
end

puts safe_divide(10, 2)
puts safe_divide(10, 0)
Output
Division attempt finished
5
Division attempt finished
Cannot divide by zero: divided by 0

Rescue Modifier & Custom Exceptions

Use the one-line rescue modifier for quick fallbacks, and subclass StandardError for domain-specific errors.

Ruby 
risk = 0
result = 100 / risk rescue "safe fallback"
puts result        # safe fallback

class InsufficientFundsError < StandardError; end

def withdraw(balance, amount)
  raise InsufficientFundsError, "Only $#{balance} available" if amount > balance
  balance - amount
end

begin
  withdraw(50, 200)
rescue InsufficientFundsError => e
  puts "Error: #{e.message}"
end
Output
safe fallback
Error: Only $50 available
Exception When it happens
ZeroDivisionErrorDividing by zero
NoMethodErrorCalling a method that doesn't exist
ArgumentErrorWrong number of arguments
TypeErrorOperation on incompatible types
KeyErrorHash key not found

end

rescue ValidationError => e
  puts "Error: #{e.message}"
end

Gems & Intro to Rails

Gems are Ruby's packages — installable libraries with gem install. Bundler manages them per project via a Gemfile.

Bash 
gem install rails        # install a gem
gem list                  # list installed gems
gem search json           # search the gem registry

Bundler & the Gemfile

Declare dependencies in a Gemfile, then run bundle install to lock them into a Gemfile.lock for reproducible builds.

Gemfile 
source "https://rubygems.org"

gem "rails", "~> 7.1"
gem "pg"
gem "puma"
gem "nokogiri", group: :scraping

group :development, :test do
  gem "rspec"
end

Intro to Ruby on Rails

Rails is an MVC web framework built on Ruby. It follows Convention over Configuration and Don't Repeat Yourself. Requests flow: Router → Controller → Model → View.

Bash 
rails new blog
cd blog
rails generate scaffold Article title:string body:text
rails db:migrate
rails server   # http://localhost:3000

The MVC Pattern

  • Model — data & business logic (e.g. Article)
  • View — HTML templates (ERB files)
  • Controller — routes requests, binds model to view

Rails gives you everything to ship a web app fast — routing, ORM (ActiveRecord), migrations, templating, and asset handling. Learn Ruby first, then Rails makes sense.
